A fast, accessible block theme for corporate, industrial and B2B businesses. Ready-made sections for services, products, partners and contact info.

== Description ==

FlowCraft is a full-site-editing (block) theme built for companies that sell products or services to other businesses: consulting firms, manufacturers, distributors, agencies and industrial suppliers.

It ships with ready-made block patterns (hero banner, services grid, about/stats section, product or project gallery, partner logos with testimonial, call-to-action banner, and a contact section) that you assemble and edit entirely in the WordPress Site Editor — no page builder plugin required. Every color, font size and spacing value is exposed through theme.json, so the whole site can be restyled from Appearance > Editor without touching code.

FlowCraft is free and 100% GPL. A separate FlowCraft Pro add-on (sold independently, not required to use this theme) adds extra patterns, a header/footer builder and WooCommerce templates for stores that also sell online.

== Installation ==

1. In your WordPress admin, go to Appearance > Themes > Add New > Upload Theme.
2. Upload the flowcraft.zip file and click Install Now, then Activate.
3. Go to Appearance > Editor to customize the homepage patterns, header, footer, colors and typography.
4. Create a static page, add the "Homepage" template if desired, and set it as your homepage under Settings > Reading (a front-page.html template is already included).

== Frequently Asked Questions ==

= Do I need a page builder plugin? =

No. FlowCraft is built entirely with WordPress core blocks and the Site Editor.

= Where do the demo images come from? =

They are original abstract graphics and icons created specifically for this theme (no stock photography), so there are no licensing questions when you redistribute or resell the theme. Swap them for your own photography from the Site Editor whenever you're ready.

= Does this theme require any plugins? =

No plugins are required. If you want a working contact form, add your preferred form plugin's block inside the "Contact details" pattern.
